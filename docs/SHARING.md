# Sharing

Sharing: portable

The app is one HTML file with no owner data, no paths and no external loads, the README addresses any person with a folder of embroidery files, and the repo carries an MIT license. The owner's personal address appears in two places the owner accepted on 2026-11-11: the 32 public commits, where a rewrite would change every commit hash, and the `.mailmap`, which must name the old addresses to map them to a noreply address. `docs/AUDIT-ACCEPTED.md` records both.
