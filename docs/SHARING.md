# Sharing

Sharing: portable

The app is one HTML file with no owner data, no paths and no external loads, the README addresses any person with a folder of embroidery files, and the repo carries an MIT license. The one open item is the personal address in the 32 public commits. The owner chose on 2026-11-11 to keep the history, because a rewrite changes every commit hash on a public repo. A `.mailmap` maps the old addresses to a noreply address for tools that read it, and `docs/AUDIT-ACCEPTED.md` records the decision.
