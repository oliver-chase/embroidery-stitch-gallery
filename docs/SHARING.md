# Sharing

Sharing: portable after fixes

The app is one HTML file with no owner data, no paths and no external loads, and the README addresses any person with a folder of embroidery files, so it is built to be shared. Two items stay open: the license, which the owner chooses, and the personal address in the public commit history, which the owner decides whether to rewrite. A `.mailmap` maps the old addresses to a noreply address for tools that read it.
